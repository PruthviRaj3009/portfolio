============================================================
  HOW TO RUN — Raj Portfolio (React frontend)
============================================================

You can run this in TWO ways. Pick ONE.

------------------------------------------------------------
  OPTION A — Plain Node (simplest, frontend only)
------------------------------------------------------------
Use this just to preview the website.

1. Install Node.js (LTS) from https://nodejs.org  (skip if already installed)
   Check it:   node --version

2. Open a terminal INSIDE this folder (the one with package.json).

3. Install dependencies (first time only, ~1-3 min):
   npm install

4. Start it:
   npm run dev

5. Open the link it prints, usually:
   http://localhost:5173

   Stop the server with Ctrl + C.

NOTE: The "Send Message" button on the Contact section will show an
error unless a backend is running. The rest of the site works fully.


------------------------------------------------------------
  OPTION B — Docker (frontend + backend together)
------------------------------------------------------------
Use this to run the frontend AND connect it to your backend.

PREREQUISITE: Install Docker Desktop and make sure it is RUNNING.
   https://www.docker.com/products/docker-desktop/
   Check it:   docker --version

1. Open docker-compose.yml in this folder and edit the 3 spots
   marked  «EDIT»  in the "backend" service:
     - context: ../backend   -> path to YOUR backend Dockerfile folder
                                 (or replace the build: block with
                                  image: yourname/your-backend:latest)
     - expose: "8000"        -> the port your backend listens on
     - environment:          -> any env vars your backend needs

   If your backend port is NOT 8000, also change "8000" in nginx.conf
   (the line: proxy_pass http://backend:8000;)

2. Open a terminal INSIDE this folder and run:
   docker compose up --build

3. Open:
   http://localhost:8080

   The frontend is served by Nginx, which forwards /api requests to
   the backend container — so NO CORS setup is needed.

4. Stop everything:
   docker compose down


------------------------------------------------------------
  RUN ONLY THE FRONTEND IN DOCKER (no backend)
------------------------------------------------------------
   docker build -t raj-portfolio-frontend .
   docker run -d -p 8080:80 --name raj-portfolio raj-portfolio-frontend
   -> open http://localhost:8080
   stop:  docker stop raj-portfolio
