SECTIONS TO DESIGN (single page scroll)

   - Navigation: Home, About, Skills, Projects, Experience, Contact
   - Hire Me button with gradient border
   - Blur background effect when scrolling

2. HERO SECTION (full screen, 3D elements)
   - Large heading: "Hi, I'm Pruthviraj" 
   - Subheading with typing animation placeholder:
     "Python Developer | Django Expert | Full Stack"
   - Two CTA buttons:
     → "View My Work" (gradient filled)
     → "Download Resume" (outline)
   - Right side: 3D floating developer avatar or 
     abstract 3D geometric shape (sphere with 
     orbit rings, glowing purple/cyan)
   - Floating code snippet card (glass morphism):
     showing Python/Django code
   - Animated particle background or grid lines
   - Scroll down indicator with bouncing arrow

3. ABOUT SECTION
   - Left: Profile photo in hexagon frame with 
     glowing purple border animation
   - Floating badge cards around photo:
     → "2+ Years Experience"
     → "10+ Projects"
     → "Open to Work"
   - Right: About text paragraphs
   - Stats row: Projects Done | Technologies | 
     Experience | Certifications
     (large numbers with gradient color)

4. SKILLS SECTION
   - Section title with gradient underline
   - Tabs: Languages | Frameworks | Databases | Tools
   - Skill cards in grid layout:
     → Icon + skill name
     → Animated progress bar with gradient fill
     → Glowing border on hover
   - 3D floating tech icons scattered in background

5. PROJECTS SECTION (sliding carousel)
   - Section title
   - Horizontal scrolling card slider
   - Each project card:
     → Full screenshot/image on top
     → Glassmorphism overlay on hover
     → Project title (bold white)
     → Short description (gray text)
     → Tech stack tags (pill shaped, gradient border)
     → Two icon buttons: GitHub | Live Demo
     → Hover effect: card lifts up with glow shadow
   - Navigation arrows left/right
   - Dot indicators below slider
   - "View All Projects" button

6. EXPERIENCE SECTION (vertical timeline)
   - Center vertical glowing line (gradient purple to cyan)
   - Experience cards alternating left and right
   - Each card:
     → Company name (bold)
     → Role with gradient text
     → Date range badge
     → Bullet points of work done
     → Tech stack used tags
   - Glowing dot on timeline for each entry

7. EDUCATION SECTION
   - Card grid layout
   - Each card:
     → University/college icon
     → Degree name
     → Institution name
     → Year range
     → Grade/CGPA badge
   - Cards with subtle gradient border
   - Hover: card glows and lifts

8. CERTIFICATES SECTION
   - Horizontal auto-scrolling strip (infinite loop)
   - Certificate cards:
     → Certificate image/icon
     → Title
     → Issuer name
     → Date
     → View Certificate button

9. ACCOLADES / ACHIEVEMENTS SECTION
   - Trophy icon section header
   - Achievement cards in a 3-column grid
   - Each card:
     → Category badge (Award/Achievement/Competition)
     → Trophy or medal 3D icon
     → Achievement title (bold)
     → Issuer and date
     → Subtle gradient card background
   - Gold/silver/bronze color coding by category

10. CONTACT SECTION
    - Split layout
    - Left side:
      → "Let's Work Together" heading
      → Email, Phone, Location with icons
      → Social media icon links
        (GitHub, LinkedIn, Twitter, WhatsApp)
    - Right side contact form:
      → Name input (dark glass input field)
      → Email input
      → Subject input
      → Message textarea
      → Send Message button (full gradient)
    - Subtle 3D envelope or chat bubble graphic

11. FOOTER
    - Logo + tagline
    - Quick navigation links
    - Social icons row
    - Copyright text
    - "Made with Django & ❤️" text
